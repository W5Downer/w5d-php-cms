# W5D — 130 Services Specification

> **Source of truth for the 130 services.** The CMS seeds its `services` table from this file on first boot. Owner edits in the admin dashboard are stored in the DB (this file remains the documentation reference).
>
> **Format per service:**
> `### {id} · {title}` followed by slug, macro, placement, short description, long description.
>
> **Macro slugs:** `cultures`, `built`, `sciences`, `governance`, `technology`
> **Placements:** `Real 1.0`, `Between 1.0`, `Real 0.5 / Virtual 0.5`
